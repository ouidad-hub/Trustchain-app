# Trustchain-app
Trustchain.ai est une app Streamlit sur Azure alliant IA et confiance numérique. Elle orchestre un système innovant de 6 agents autonomes. L'interface interactive permet de visualiser en temps réel l'architecture, de tester la synergie et les modèles de ces agents, et de démontrer l'efficacité de la solution de manière fluide et sécurisée.
